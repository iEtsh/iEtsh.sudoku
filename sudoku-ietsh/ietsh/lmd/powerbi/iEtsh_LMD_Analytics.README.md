# iEtsh LMD Analytics — Power BI Desktop Project

This is the authored Power BI project (PBIP), not a replacement web dashboard.

## Open the report
Open **iEtsh_LMD_Analytics.pbip** in Power BI Desktop. The project contains the semantic model and four report pages:
- Overview
- Puzzle Performance
- Growth & History
- Data Quality

On the first data refresh, choose **Anonymous** for the public GitHub workbook source if Power BI asks for credentials.

## Data model
The model imports the existing workbook generated by the repository's LMD update workflow:
`https://raw.githubusercontent.com/iEtsh/iEtsh.sudoku/main/sudoku-ietsh/ietsh/lmd/exports/iEtsh_LMD_Analytics.xlsx`

It includes PuzzleMasterData, ObservationLog, PuzzleTrends, and a Date table, with one-to-many relationships and historical measures that reconstruct each puzzle's last known solve total as of the selected date.

## Theme
The `iEtshDark.json` file is the custom dark theme. In Power BI Desktop, use **View → Themes → Browse for themes** and select this file if Desktop does not automatically apply it.

## Website publishing
GitHub can host the PBIP source files, but GitHub cannot render a Power BI report interactively. To embed this exact report on the website, publish it from Power BI Desktop to your Power BI workspace and then provide the resulting embed URL. A Publish to web URL is public to anyone who obtains it.
