# iEtsh LMD Analytics — Power BI

## Open the report
Open `iEtsh_LMD_Analytics.pbip` in Power BI Desktop. The project uses the workbook generated by the existing LMD export workflow.

## Report pages
1. **LMD Ultimate Analytics** — a single-page showcase dashboard with six KPI cards, historical platform trend, area and stacked-area charts, active/inactive donut, stacked and 100% stacked comparisons, waterfall daily change, treemap contribution, scatter/bubble analysis, ribbon ranking, puzzle rankings, rating trend, daily growth, difficulty profile, and a full-detail table.
2. **Overview**
3. **Puzzle Performance**
4. **Growth & History**
5. **Data Quality**

The primary page uses built-in Power BI visuals only; no AppSource custom visual dependency is intended. The six KPI cards use the classic built-in Card visual for broader Desktop compatibility.

## Data source
`https://raw.githubusercontent.com/iEtsh/iEtsh.sudoku/main/sudoku-ietsh/ietsh/lmd/exports/iEtsh_LMD_Analytics.xlsx`

The workbook is generated by the existing repository workflow. No private keys are included.

## Notes
The PBIP source project is not itself an embeddable report. Publish it to a Power BI workspace before creating an embed link. A Publish to web link makes the report and its data public; a website password gate does not make that link private.
